# Privacy notice — Google Earth Placemark Cleaner

**Your KML and KMZ data is processed on your own device.** This is a static, client-side utility created by WEBNIX STUDIO.

## What happens to your map

When you select a file, the application reads it using browser file APIs. The application scans KML documents (including KML content inside KMZ ZIP archives), lets you choose placemark icons, modifies the presentation of selected icons, and creates a local file download. There is no HTTP file upload or server-side map processing.

## What we do not collect or store

The application does not require an account and does not contain analytics, tracking pixels, a database, or an upload endpoint. **WEBNIX STUDIO does not receive, store or retain your uploaded map files or map content on our servers.**

## Ordinary network activity

When you visit the website, the browser fetches static website files from the hosting service (for example, GitHub Pages). That hosting service and your browser may create standard request logs or caches. Your selected KML/KMZ document is not transferred with those requests. The optional service worker caches public web assets, not selected user files. If you open the downloaded website offline, no network connection is required for tool logic.

## Your responsibility

Keep a backup of the original KML/KMZ and verify output in Google Earth Pro. The color detector is heuristic and may group some custom icons under “Other / Custom.” Large archives can consume substantial local browser memory.
