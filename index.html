05 / ANSWERSCOMMON QUESTIONS

GOOD TO
KNOW.

How do I remove Google Earth placemark icons but keep the names?+

Export your Places folder as a KML or KMZ, import it above, select the desired icon colors or individual markers, then save the result. The tool hides the selected icons without deleting those named Point placemarks.

Can I remove only yellow or blue pushpins?+

Yes. Select any available color group, including Google Earth blue paddle/teardrop markers, or check exact survey numbers. Other colors remain unchanged.

Will survey boundaries and Gujarati names remain?+

Yes. Only eligible, named point icon styles are edited. Polygon outlines, LineStrings, survey labels and Gujarati Unicode names are retained. Check your exported file in Google Earth before relying on it for critical work.

Are KMZ files uploaded to WEBNIX STUDIO servers?+

No. The website works locally in the browser with a bundled ZIP library. It does not send map data to any server.

Is this the same as deleting placemarks?+

No. It changes presentation styles by setting an icon scale to zero. Coordinates and named point records remain in the saved KML or KMZ.

Is this an official Google Earth product?+

No. This is an independent utility created by WEBNIX STUDIO and is not affiliated with, endorsed by, or sponsored by Google. Google Earth is a trademark of Google LLC.
